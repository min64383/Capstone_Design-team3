# 90° 회전 녹화 비교 결과

2026-11-19. 기준 main `0a89c71b1eb888fdf95acf02f7eca2cedfa5b906`에 기존 실험 브랜치의 높이 겹침 보정과 재생 옵션을 옮겨 평가했다. 실험 브랜치는 `experiment/rotation-real-90-review`다. 재현 명령과 열 정의는 [실행 절차](ROTATION_REAL_AB.md), 숫자 원본은 [summary CSV](rotation_real_20261119.csv)에 있다.

네 세션 × 일곱 변형을 PC에서 고정 처리 시간 10 ms로 재생했다. 모든 변형에 소리 설정과 머리 오프셋 [0, 0.2, -0.1] m를 적용했다. 가슴 고정 변형은 같은 값을 `heading.chestMount.headOffsetBodyM`에도 넣었다. 장착 yaw는 0°로 가정했다. M42 카메라 결합의 2.3°는 기존 합성 비교값이며 이번 녹화로 조정하지 않았다.

아래 값은 `testdata/README.md`의 회전 시작(카메라 yaw 변화의 10% 시점, 0.1초 근사) 이후 처음 STOP이 나온 시각이다. 장애물 진입부터의 반응 지연이나 기기의 실제 음성 지연으로 해석할 수 없다. 서로 다른 변형 사이의 첫 출력 시각 차이를 비교한다. 물체 위치 정답이 없어 변형 사이 경고 대상의 동일성은 확인하지 못했다.

| 세션 | 기존 이동 방향 | M42 카메라 결합 | 가슴 고정 | 가슴 고정 + 근거리 STOP | 여기에 5cm 보정 추가 |
|---|---:|---:|---:|---:|---:|
| 145235, 오른쪽 대조 | STOP 없음 | STOP 없음 | STOP 없음 | STOP 없음 | STOP 없음 |
| 145251, 왼쪽 대조 | STOP 없음 | STOP 없음 | STOP 없음 | STOP 없음 | STOP 없음 |
| 145335, 왼쪽 회전 후 물체 | 1,097.4 ms | 697.4 ms | 686.7 ms | 686.7 ms | 686.7 ms |
| 145348, 오른쪽 회전 후 물체 | 1,183.6 ms | 746.2 ms | 772.9 ms | 772.9 ms | 772.9 ms |

가슴 고정의 첫 STOP은 기존 이동 방향 대비 두 장면 모두 약 410.7 ms 빨랐다. M42 결합은 각각 400.0·437.3 ms 빨랐다. 이 두 장면에서는 카메라 방향을 사용하는 두 방식의 첫 안내 시각이 가까웠다. 몸 방향 정답이 없어 두 방식 중 하나를 기본값으로 선정하기에는 자료가 부족하다.

가슴 고정·근거리 STOP·근거리 STOP+높이 겹침의 `guidance.csv`는 각 세션에서 전체 바이트가 같았다. 근거리 STOP 추가 출력 시간은 모두 0초였다. 높이 겹침 보정의 실제 녹화 추가 효과는 이번 자료에서 관측되지 않았다. 대조 장면 두 개에서는 모든 변형에 STOP이 없었다. 입력 파일 경고는 28회 모두 0개였다.

근거리 진단 로그에서 실제 두 물체 세션의 크기 통과 후보는 각각 145·133장, 두 장 확인 통과는 보정 OFF 137·128장 / ON 142·130장이었다. 이미 확인된 지도 물체와 겹치는 후보를 제외한 근거리 출력은 양쪽 모두 각각 2·6장이었다. 이 8장의 처리 완료 시 정보 나이는 172.4~195.5 ms로, 근거리 프로파일의 `maxAgeMs` 150 ms를 모두 넘었다. `Policy.commands`에서 이 후보들이 만료되어 소리 명령으로 이어지지 않았다.

추가 진단으로 근거리 `maxAgeMs`만 기존 일반 안내의 `policy.maxInfoAgeMs`(현재 500 ms)로 맞췄다. 시스템의 기존 상한을 사용했고, 이번 두 영상에 맞춰 수치를 탐색하지 않았다. 이 진단 설정은 실험 실행기 안에서 생성한다.

| 진단 변형 | 145335 첫 STOP | 145348 첫 STOP | 대조 두 장면 |
|---|---:|---:|---|
| 가슴 고정, 근거리 기본 150 ms | 686.7 ms | 772.9 ms | STOP 없음 |
| 근거리 상한을 시스템 500 ms로 맞춤 | 596.1 ms | 575.6 ms | STOP 없음 |
| 위 진단에 5cm 보정 추가 | 596.1 ms | 575.6 ms | STOP 없음 |

정보 나이 상한을 맞추면 가슴 고정 기준에서 각각 90.7·197.3 ms 먼저 STOP이 나온다. 기존 이동 방향 기준으로는 501.3·608.0 ms 이르다. 이때 근거리 STOP 출력 시간은 각각 0.0693·0.2080초다. 5cm 보정을 더 켠 결과는 시스템 상한 진단에서도 안내 바이트가 같았다. 이 비교는 150 ms 상한이 이번 기록의 근거리 경고를 막았다는 원인 확인이며, 500 ms를 제품 기본값으로 채택하려면 다른 동작·장소의 정답과 실제 기기 평가가 필요하다.

`cameraYawErrorOver5Fraction`은 회전 시작 이후 블록이 쓴 카메라 yaw를 대리 기준으로 사용한다. 가슴 고정 방식이 카메라를 따라가도록 설계되어 있어, 이 값으로 몸 방향 추정의 독립적인 정확도를 주장할 수 없다. 원본에는 장착 방식·상대 yaw·물체 실측 위치가 기록되지 않았다. 사용자 요청에 따라 하네스와 이후 기록된 실측 오프셋을 가정했다. 물체 장면의 RGB에는 글씨가 붙은 유리문이 보인다.

같은 코드로 합성 실험을 다시 실행했다.

| 실험 | 보정 OFF | 보정 ON |
|---|---:|---:|
| 독립 잡음 seed 101~120, ±90°·0.5초 급회전 40건, STOP 표본 / 조건 충족 표본 | 112/160 (70.0%) | 114/160 (71.25%) |
| 위 40건 첫 STOP 지연 평균 | 40.00 ms | 38.33 ms |
| 위 40건 첫 STOP 지연 최댓값 | 100.00 ms | 66.67 ms |
| 인접 물체 9배치에서 이전 ID를 잘못 이어받은 배치 | 5/9 | 5/9 |

첫 STOP이 빨라진 것은 오른쪽 90°·seed 104 한 건(100.00 → 33.33 ms)이며 나머지 39건은 같았다. 위 숫자는 합성 장면의 표본 비율이다. 실제 보행의 오탐률·미탐률은 별도 정답이 필요하다. 기존 인접 오연결 5건도 남아 있다.

기존 전체 합성 실험도 186건·558개 구간 행으로 완료했다. 원래 ±90°·0.5/1초·잡음 0/7의 16개 배치에서 회전 중 조건 충족 STOP 표본은 가슴 고정 12/72, 근거리 STOP 추가 55/72였다. 빈 방·옆벽 대조의 22개 배치 × 두 방식, 총 44회에서는 STOP이 없었다. 이 전체 실험은 현재 기본 근거리 프로파일의 확인 폭 0.079 m를 사용하고, 위 40개 쌍 비교는 양쪽 모두 초기·확인 폭 0.08 m를 사용해 높이 겹침 효과만 비교했다.

이번 범위는 M62의 회전 재생 비교다. 실제 기기의 처리 지연·음향 출력·장시간 발열, 다른 장착 각도와 장소, 정확한 물체 위치 정답은 후속 확인 항목이다. M62의 다른 녹화·M63의 기기 안정성 평가도 별도로 남아 있다.

검증은 Gradle 9.8.0·JDK 21에서 core 전체 510개(실패 0), 진단 연결 후 관련 core 22개 재검증(실패 0), Viewer 18개(실패 0), `python tools/analysis/test_analysis.py` 자체 점검을 통과했다. Viewer 기존 테스트가 요구하는 Windows 경로를 Linux에서도 열 수 있도록 경로 구분자 처리를 한 줄 수정했다. 실제 녹화의 기본 다섯 변형은 독립 실행을 포함해 재생 로그 20개씩을 비교했고 모든 안내 로그와 요약 CSV가 같았다. 진단 연결 뒤에도 기본 다섯 변형의 요약이 같다.
