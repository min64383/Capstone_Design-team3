HEARSPACE 화면 시안 — 스플래시 · 작동 · 설정

기준: 확정 로고(2026-10-30)의 색, 명세 MVP §11.2(사용자 모드: 화면을 보지 않고 쓴다, 화면 전체가 버튼 하나, 검은 배경·고대비 큰 글자, TalkBack 호환), IMPROVE_SPEC §2(가슴 하네스, 걷는 동안 화면은 몸 쪽). 화면을 보는 때는 시작 전·멈춘 뒤·도와주는 사람·저시력 확인·시연이다. 크기는 dp(시안의 px = dp). 새 기능 표시는 지금 앱에 없는 기능이다.

1. 색 역할

색상은 로고 원에서 가져오고 밝기는 목표 대비를 넘는 가장 밝은(흰 배경)·어두운(검은 배경) 값으로 계산했다(OKLCH). 목표 7 · 4.5 · 3은 WCAG 2.1 기준(AAA 글자 · AA 글자 · 부품 경계), 15와 11은 저시력을 위해 직접 정한 여유다. 로고 자체의 파스텔 색은 흰 배경에서 대비가 1.5~3.1이라 뜻을 전하는 글자·그래픽에는 쓰지 않고 로고·장식에만 쓴다.

2. 스플래시

Android 12 이상은 앱을 열 때 시스템 스플래시(배경색 + 가운데 아이콘 + 아래 브랜드 이미지)를 늘 보여 준다. 따로 스플래시 화면을 만들면 두 번 뜨므로 이 틀(SplashScreen API)에 맞춘다: 아이콘 배경 없이 288 dp 칸, 보이는 원 지름 192 dp(점선) 안에 로고, 아래 브랜드 200×80 dp에 글자 로고. 준비가 끝나면 바로 작동 화면으로 넘어간다.

3. 작동 화면 (사용자 모드)

늘 검은 배경(명세 §11.2, 배터리·저시력). 화면 전체가 버튼 하나: 두 번 탭 = 시작·일시정지·재개, 길게 누르기 = 종료(TalkBack에서는 두 번 탭 · 두 번 탭 후 유지). 위에 상태 한 줄(40 dp 굵게), 가운데에 그림, 아래에 조작 안내. 설정 단추는 시작 전에만 보인다(걷는 중 잘못 눌리지 않게). 상태 문구는 지금 앱 그대로다.

4. 설정

시작 전 화면의 설정 단추로 연다. 기기 테마(또는 아래 테마 설정)를 따른다. 누르는 줄 높이 56 dp 이상(터치 최소 48 dp), 글자 18 dp. 넣지 않은 것과 이유: 진동 끄기(소리가 끊겼을 때 알리는 길이 진동뿐이라 — 안전 신호, M40), 앱 안 음량(너무 낮추면 안내가 안 들림 — 기기 음량 버튼만), 안내 거리·민감도(명세의 가설 값, 개발 모드 실험 패널 소관), 개발 모드(명세 §11.3대로 별도 런처 아이콘).
