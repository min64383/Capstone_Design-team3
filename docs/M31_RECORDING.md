# M31 보정 녹화 K01 체크리스트

기준: `docs/IMPROVE_SPEC.md` v0.3.29 §11.2, milepost M31 설계(`milepost/pdf/scene-map/M31-design.pdf`, 로컬 전용). 절차는 `docs/M12_0_RECORDING.md`(M12.0 녹화)와 같고, 다른 점만 적는다.

**목적:** 끝 벽까지 거리를 미리 정해 두고 찍어서, 깊이의 **절대 편향**과 **같은 거리에서 세션마다 달라지는 편향**을 잰다. M30 오차 모델은 면마다 상수를 빼서 이 둘을 볼 수 없었다(교차 검사 12묶음 중 3묶음만 목표). 결과는 M32 원시 깊이 지도의 가중치·허용치 근거로 쓴다.

## 0. 무엇을 찍나

| 장면 | 구성 | 회차 |
|---|---|---|
| K01 | 기존 복도 C의 끝 벽 정면, 카메라에서 벽까지 1.0·1.5·2.0·3.0·4.0 m, 손 파지 정지 15 s, 물체 없음 | 거리마다 2회(10세션) |
| (녹화 없음) | C의 천장 높이 실측 | 1회 |

혼자 약 20~30분. 보조자는 없어도 된다.

## 1. 촬영 전

- [ ] 앱은 `m31/k01` 브랜치를 `./gradlew :app:installDebug`로 설치(장면 목록에 `K01`이 있는지 확인)
- [ ] S10 충전, 저장 공간 1 GB 이상(15 s 세션 약 50 MB)
- [ ] 줄자(5 m 이상), 테이프
- [ ] 직전 녹화가 있었다면 5분 이상 쉬어 기기 온도를 낮춘다

## 2. 현장 준비

- [ ] **천장 높이**: 바닥에서 천장까지 줄자로 잰다. 보행선 위 두 곳(끝 벽 1 m 앞, 4 m 앞)을 재서 둘 다 적는다
- [ ] **표시**: 보행선(복도 가운데) 위에 끝 벽에서 **1.0, 1.5, 2.0, 3.0, 4.0 m**인 자리에 테이프 표시. 4.0 m는 E 세션 시작 표시와 같은 자리다
- [ ] **끝 벽 무늬**: 끝 벽이 민무늬라면 눈높이에 A4 종이 몇 장을 붙인다(깊이가 비지 않게). 붙였으면 기록표에 적는다
- [ ] 파지 오프셋은 지금까지와 같은 값

## 3. 절차 (표시마다)

1. 폰 **카메라가 표시 바로 위**에 오도록 서서, 기준 파지(가슴 앞 중앙, 세로)로 끝 벽을 **정면으로** 본다
2. 장면 `K01`을 고르고, `TRACKING`이 된 뒤 녹화 시작
3. 몸을 움직이지 않고 **15 s** 정지한 뒤 정상 종료
4. 순서는 1.0 → 1.5 → 2.0 → 3.0 → 4.0 m로 한 바퀴 찍고, **같은 순서로 한 바퀴 더** 찍는다(같은 거리 두 회차 사이에 시간을 둔다)
5. 지나가는 사람이 끝 벽 앞을 가리면 그 회는 다시 찍는다

## 4. 정답 파일

세션마다 `data/sessions/<세션ID>/annotations/obstacles.json`. 같은 거리의 두 회차는 복사한다. `D` = 표시 거리(m), `H` = 천장 높이(m, 두 값의 평균).

```json
{
  "version": 2,
  "scene": "K01",
  "distanceFrom": "camera",
  "estimated": false,
  "note": "K01 카메라→끝 벽 D m, 손 파지 정지 15 s. 천장 H m(두 곳 a·b). 2026-10-xx, 복도 C(폭 1.04 m), 측정자",
  "obstacles": [
    { "name": "wall_left",  "type": "FLOOR", "kind": "structure", "min": [-0.62, 0.0, -0.5], "max": [-0.52, H, D] },
    { "name": "wall_right", "type": "FLOOR", "kind": "structure", "min": [0.52, 0.0, -0.5],  "max": [0.62, H, D] },
    { "name": "wall_end",   "type": "FLOOR", "kind": "structure", "min": [-0.62, 0.0, D],    "max": [0.62, H, D + 0.1] },
    { "name": "ceiling",    "type": "FLOOR", "kind": "structure", "min": [-0.62, H, -0.5],   "max": [0.62, H + 0.1, D] }
  ]
}
```

- `distanceFrom: "camera"`이므로 읽는 쪽이 머리 원점으로 옮긴다(z + 0.39 m). 벽 두께 0.10 m는 실측이 아니다(M30과 같음)
- E 10세션 정답도 같은 규칙으로 고친다: 벽 `max.y` 2.4 → `H`, `ceiling` 상자 추가(`min [-0.62, H, 0.0]`, `max [0.62, H + 0.1, 4.0]`)

## 5. 촬영 후

- [ ] `powershell -ExecutionPolicy Bypass -File tools\setup\pull-sessions.ps1 -All`
- [ ] 세션마다 `spike_check.py`로 길이 ≥ 12 s, `TRACKING`, 원시 깊이 장 수 확인. 빠진 것은 다시 찍는다
- [ ] 정답 파일 작성, 기록표 채우기
