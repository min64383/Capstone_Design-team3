# M13 맵(복셀) 정확도 보고서

기준: `docs/IMPROVE_SPEC.md` v0.2.2 §6.1. 작성 2026-10-05. 데이터: git의 정답 세션(`testdata/sessions`) 9개(S01 1·S02 3·S03 3·S07 2), PC 오프라인 재생(`sweep.py`, `sweeps/m13_map.json`).
**결정**: 기본값은 `floor.tolerancePerM` 0.08 → 0.04만. 그림자 거르기는 합성 합격 장면을 깨서 꺼 둔다(§4).

## 1. 무엇이 틀렸나

평가 GUI에서 "복셀이 실제와 다르다"(사용자 확인)를 데이터로 나눠 보면 원인은 하나가 크다.

- **평활 깊이의 가짜 면**: ARCore 평활 깊이가 앞 물체 윤곽과 뒤 배경 사이를 보간해, 캐리어 윗모서리에서 뒤 문까지 약 1.5 m 이어지는 면을 만든다. 걷는 위치에서 보면 물체 뒤 공간은 늘 그 물체의 그림자 속이라, 새 시점마다 같은 자리에 다시 생기고 빈 공간 감쇠로 지워지지 않는다. 이 면이 캐리어와 문을 이어 한 물체로 합쳤다.
- 실제 표면의 깊이 잡음(두께 2.8~4.5 cm)·편향(1~2 cm)·걷는 중 지연(약 65 ms × 속도)은 복셀 크기(5 cm)보다 작다.
- 이번 녹화의 카메라 흔들림은 작았다(회전 p95 16~22°/s). 진행 방향은 이미 카메라 방향이 아니라 이동 궤적으로 정한다(`Heading`). 흔들림의 영향은 손목 회전 녹화로 따로 재야 한다.

## 4. 결정

**기본값은 바닥 허용치 `floor.tolerancePerM` 0.04만 바꾼다. 그림자 거르기는 꺼 둔다**(`depth.shadowRadiusPx` 0, 사용자 결정 2026-10-05).

- 처음 권고는 그림자 r16 + 바닥 0.04였고, 사용자는 보수안 r12 + 바닥 0.04를 골랐다. 그런데 r12를 기본으로 넣자 **합성 합격 장면 2개가 깨졌다**(IMPROVE_SPEC §12):
  - SC-14 좁은 복도: 통로 안쪽 벽이 비스듬히 보이면 벽의 먼 쪽 픽셀마다 같은 벽의 가까운 쪽이 반경 안에 있어 "그림자"로 지워진다. 벽이 조각나 벽 조각(1.2 m)을 장애물로 안내했다.
  - SC-08·SC-02 추적: 가까이 가면 상자 윗면이 앞면의 "그림자"로 지워져 상자가 두 조각으로 남는다.
- 원인: 한 장면 안에서는 평활 깊이의 가짜 면과 **비스듬히 보이는 실제 면**(벽, 물체 윗면)이 구별되지 않는다. 실제 녹화 지표가 이를 놓친 것은 `free`가 물체 뒤 통로 가운데만 보고, 녹화한 복도 벽은 통로 밖이었기 때문이다(S01 끝 문 복셀 감소 364 → 246이 신호였다).
- 수직 구조 예외(같은 수평 칸의 높이 폭이 크면 벽으로 보고 거르지 않음)를 시도했으나 SC-14 실패 시점만 늦추고(0.3 s → 2.2 s) SC-08은 그대로라 되돌렸다.
- 바닥 0.04만: 전체 테스트 통과. S07 낮은 캐리어 보임 0.60 → 0.86·첫 경고 2.06 → 2.24 m·방향 오차 p95 15.4° → 11.4°. 비용: S01 오경보 0.78 → 0.83, S03 헛 복셀 79 → 108. **S02의 가짜 면(헛 복셀 75)은 남는다.**

## 5. 남은 문제

- **가짜 면은 그대로다.** 벽·물체 윗면을 지키면서 가짜 면만 지울 방법이 필요하다. 후보: 여러 프레임 일관성(가짜 면은 시점을 따라 움직이고 실제 면은 그대로 — 단 첫 탐지를 늦추지 않아야 함, 여러 시점 확인이 탈락한 이유), RGB 경계로 깊이 경계 다시 잡기, 깊이 신경망 보정(승인 필요). 합격 기준은 SC-21(가짜 면 제거)과 SC-14·SC-08(벽·윗면 유지)을 함께 통과하는 것.
- S03: 물체 뒤 멀리 이어지는 가짜 면은 그림자 반경으로도 잡히지 않음(79 → 69).
- 흔들림 강건성: 손목 회전 녹화(S10 유형) 2~3회가 필요.
- `free` 상자는 촬영 장소 영상·깊이로 정한 것(실측 아님). 문·벽 위치는 각 세션 깊이에서 4.3~6.0 m로 확인해 상자를 그 앞에서 끝냈다.
