## 1. 현장 준비 (1회)

- [ ] 바닥에 **시작 표시**(테이프 십자) 1개, 거기서 앞으로 **보행선 테이프 6 m 이상**. 정렬이 이 선에 직선을 맞추므로 곧아야 한다(`align.fitLengthM` 2.0 m)
- [ ] 보행선 위에 0.5 m마다 눈금 표시(장애물 위치 측정용)
- [ ] **파지 오프셋 측정** (아래 값으로 이미 기록돼 있으면 같은 자세로 고정하고 생략 가능)
  - 기준 파지: 가슴 앞 중앙, 높이 약 1 m, 카메라가 진행 방향
  - 기록값: 카메라는 두 눈 중앙보다 **아래 0.50 m, 앞 0.30 m** (`head.offsetFromCameraM = [0, 0.5, −0.39]`)
  - 키가 다른 사람이 찍으면 다시 측정해서 `docs/FORMAT.md` 세션 기록 표에 적는다. **녹화 화면에 입력해도 meta.json에는 0으로 남는 알려진 문제가 있다**
- [ ] **한 사람이 전부 촬영**(파지·걸음 일관성). 불가능하면 촬영자를 세션 메모에 적는다

## 2. 매 세션 공통 절차

1. 개발 모드 → 녹화 → **장면 ID를 맞게 선택**(S01~S10, T01). 틀리면 세션 폴더 이름의 `_S02` 부분이 틀린다
2. 시작 표시 위에 **머리**가 오도록 서고, 폰을 기준 파지로 든다
3. 추적 상태가 `TRACKING`이 된 것을 확인하고 녹화 시작
4. **2~3초 정지**(추적 안정화), 그다음 보행선을 따라 직진. 걸음은 초속 약 1 m
5. 앞쪽 장애물 1.0 m 이내까지 접근한다(보조자가 안전 확인). 부딪히지 않는다
6. 약 6 m 걷거나 장애물을 지난 뒤 정지, **정지 후 2~3초 더 녹화**하고 종료
7. 종료 화면에서 **정상 종료**(저장 완료) 확인. 앱 강제 종료 금지
8. 세션 ID를 아래 기록표에 적는다

**3회 반복할 때:** 장애물 위치는 그대로 두고(위치를 바꾸면 `obstacles.json`을 따로 써야 함), 시작 표시에서 다시 시작한다. 3회 중 1회라도 실패(추적 상실, 부딪힘, 비정상 종료)하면 그 회는 버리고 다시 찍는다.

## 3. 장면별 구성

`obstacles.json`의 `type`은 기대 높이 분류: `FLOOR`(바닥에서 시작), `BODY`, `HEAD`(머리 높이 돌출). 좌표는 정답 좌표(원점 = 시작 표시, +z 보행선 앞, +x 오른쪽, +y 위, 미터). 앞쪽 거리는 **시작 표시 기준 줄자 실측**.
통로: 폭 0.8 m(좌우 ±0.4), 길이 3.5 m, 높이 2.0 m (`corridor.*`).

## 4. T01 (10분 지속)

기존 `085205_T01`은 야외 8.5분이라 기준(10분 지속, 실내)에 맞지 않는다. 다시 찍는다.

- [ ] **(a) 녹화 모드** 10분 이상, 실내 복도를 왕복 보행. 목적은 저장 처리량·발열. 종료 후 `device.csv`(발열 상태, 배터리) 확인
- [ ] **(b) 사용자 모드** 10분 이상 실행. 목적은 실제 안내 상태에서 느린 경로 주기·발열 유지. 장애물 1~2개를 복도에 두고 왕복. 실행 로그 폴더(`.../files/runs/<시각>`)를 같이 가져온다
- 시작 전 기기 온도를 가라앉힌다(직전에 다른 녹화를 했다면 5분 이상 쉰다)
- 중간에 화면이 꺼지거나 앱이 멈추면 그 시각을 기록하고 계속한다(지속 동작 실패 자료)

## 5. 정답 파일 작성

PC에서 세션마다 `data/sessions/<세션ID>/annotations/obstacles.json`을 쓴다. 3회가 같은 배치면 한 파일을 복사한다.

```json
{
  "version": 1,
  "estimated": false,
  "note": "S02, 의자 앞 모서리 2.00 m 줄자 실측 (2026-10-xx, 복도명)",
  "obstacles": [
    { "name": "chair", "type": "FLOOR", "min": [-0.25, 0.0, 2.0], "max": [0.25, 0.9, 2.5] }
  ]
}
```

- 측정은 **시작 표시 기준**. 의자 중심이 보행선에서 벗어나 있으면 `min.x`/`max.x`에 반영
- `note`에 장소·측정 방법·측정자를 적는다. 줄자 실측이 아니면 `"estimated": true`
- 정렬이 보행선 직선 적합이므로, **보행 중 보행선에서 크게 벗어난 회**는 `note`에 적는다
