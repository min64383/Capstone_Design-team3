## 1. M13.0 합성 가장자리 평활 모드 (2026-10-07, PR #45)

- `Noise.edgeSmoothPx`: 창 안에 깊이 불연속(최대 − 최소 > 최소 × 10%)이 있는 픽셀만 유효 깊이의 평균으로 바꿔 불연속을 2r픽셀 경사로 만든다. r = 2(경사 4픽셀)는 M12.0 실측 일반 깊이의 캐리어 윗모서리 경사 p50 2~4, p90 3~5픽셀에서.
- 실측의 **뒤 배경 끌림**(경계에서 약 25픽셀 안 배경이 0.15~0.5 m 앞으로)은 넣지 않았다. 원시 깊이에는 없고, M13.1의 짧은 경사 판정 대상이 아니다.
- 기준선: SC-21 막 복셀 최대 31칸(평활 없으면 0칸)으로 **실패(의도대로)**, SC-22·SC-23 통과. 합성은 상자–벽 합쳐짐(0%)을 재현하지 않는다.

## 2. M13.1a 깊이 영상 앞단 ① 경계 판정 (2026-10-07)

### 2.1 방법

`core/frontend/EdgeDetector`(명세 §6.1.1 M13.1a 구현). 주사선(가로·세로·두 대각선)을 선형 조각으로 나누고, 두 표면 사이를 짧고 가파른 경사로 잇는 픽셀 중 두 표면 직선 어느 쪽에서도 벗어난 픽셀을 경계로 표시해 지도·바닥 추정에서 뺀다. `frontend.enabled`(기본 false).

실측에 맞춰 두 번 고쳤다.

| 단계 | 바꾼 것 | 이유(실측 E01h 151747·151835, 캐리어 윗모서리 경사 대역 픽셀 중 표시 비율) |
|---|---|---|
| 첫 구현 | 표면 = `edgeMaxRampPx`보다 긴 조각, 수평면 예외 = 높이 차 절대값 | 합성은 모두 통과했지만 실측 표시 비율 0.49·0.41, 합쳐짐 거의 그대로 |
| 수평면 예외 | 높이 변화 ÷ 깊이 변화(`levelMaxSlope`)로 판정 | 얕은 각(약 8°)의 2픽셀 막은 높이 차가 5 cm 안이라 윗면으로 오인. 표시 비율은 0.50·0.42로 거의 그대로 |
| 표면/경사 가르기 | 길이 대신 **기울기**(`edgeSteepRatio`, 픽셀당 5%) | 막 앞 뒤 벽 끌림(완만한 휨)이 6픽셀 조각으로 잘려 경사 묶음이 한도를 넘었다. 표시 비율 0.67·0.49 |

### 2.4 남은 것

- **뒤 배경 끌림**: 뒤 벽이 0.15~0.5 m 앞으로 끌려온 긴 경사는 설계상 남는다. 합쳐짐이 0이 아닌 이유의 하나다. M13.1b 영역 분할(경계를 넘지 않는 영역)과 M13.2 관측 가중치에서 다시 본다.
- 실측 경사 대역 표시 비율은 0.49~0.67이다(대역에 실제 윗면·옆면 일부도 들어 있어 상한이 1이 아니다).
- S03 오경보 증가(0.08 → 0.12)의 원인은 보지 않았다. viewer로 확인이 필요하다.

### 2.5 벽 두께와 끌림 억제 실험 (사용자 viewer 확인 뒤, 2026-10-07)

사용자 확인: S02 130646에서 캐리어는 잘 잡히지만 뒤 문이 불안정하고, 위에서 본 지도에서 5~10 cm 벽이 매우 두껍게 보인다. 캐리어 정답 상자가 약 40 cm 떠 보인 것은 core 바닥 추정(중앙값 −0.67 m, 실제 약 −1.07 m) 때문이며 M12.1의 `floor.minBelowCameraM` 0.8로 −1.04 m가 된다.

- **지도 평가 `map_eval.json`(core `MapEvalWriter`, `MapEval`)**: 정답이 있는 세션을 재생할 때마다, 정답 구조물(벽)마다 사람 쪽 앞면 근처 점유 복셀을 벽 방향·높이 칸으로 묶어 칸별 두께(면에 수직으로 쌓인 칸 수 × 복셀 크기)와 앞 치우침(가장 앞 복셀이 실제 앞면보다 나온 거리)을 쓴다. 느린 경로 15번마다와 마지막. `metrics.py` `mapWalls`, `report.py` 열(벽 두께 p50, 벽 앞 치우침 최대). 합성 복도에서 벽이 두께 ≤ 0.1 m, 치우침 ±6 cm 안임을 테스트로 확인.
- **S02 130646 뒤 문(옆 벽 제외, 정답 좌표 |x| < 0.35 m)**: 칸별 두께 중앙 15~20 cm, p90 25~30 cm. 문 위치가 다가가며 움직인다(멀 때 4.3~4.6 m → 가까이 4.5~5.0 m). 지난 자리의 복셀이 남아 두꺼워지고 물체가 불안정하다. 원시 깊이도 한 프레임부터 넓게 퍼져 해결되지 않는다.
- **E01h(정지) 캐리어 뒤 끝 벽**: 두께 p50 0.175 m, **앞 치우침 0.43 m**. 정지 장면이라 누적이 아니라 매 프레임 깊이 자체가 벽을 앞으로 당긴다(뒤 배경 끌림 + 막).
- **끌림 억제 실험(경계에서 먼 쪽 표면 8·16·24픽셀을 지도에서 뺌) — 실패, 코드에서 뺐다.** E01h 합쳐짐 0.24 → 0.08~0.10, 끝 벽 두께 0.175 → 0.10~0.125 m로 좋아졌지만 끝 벽 앞 치우침(0.39~0.43 m)은 그대로였다. 반면 S02 합쳐짐 0.19 → 0.40~0.54로 나빠졌고, **S07(낮은 캐리어) STOP 누락 0 → 1, 오경보 0.14 → 0.39~0.54**. 물체 뒤 먼 쪽이 바닥일 때 바닥 점까지 지워 바닥 추정과 물체 모양을 망가뜨린 것으로 본다.

### 2.6 제안 (사용자 결정)

1. viewer로 S02·E01h를 `{ "frontend": { "enabled": true }, "floor": { "minBelowCameraM": 0.8 } }`로 재실행해 막 판정(자홍)과 복셀을 본 뒤 `frontend.enabled`·`floor.minBelowCameraM` 기본값을 정한다.
2. 순서 변경(사용자 결정 2026-10-07): 벽 두께를 먼저 다룬다. 다음 단계는 M13.2 로그 오즈 지도(빈 칸 관측으로 지난 자리의 복셀 지우기, 거리별 관측 가중치)이고, M13.1b 영역 분할은 그 뒤. 정지 장면의 앞 치우침(매 프레임 깊이 자체의 끌림)은 지도 규칙으로 줄지 않을 것으로 보고 따로 다룬다.
