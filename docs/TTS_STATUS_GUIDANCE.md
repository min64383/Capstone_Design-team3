# 1118tts: 상태 안내와 TTS 안전 한계

## 범위와 결정 (2026-11-19)

- 기존 감지/위험도/공간음향 알고리즘은 변경하지 않는다. 상태 안내는 사용자 화면의 상태를 말로 표현할 뿐, 안전 여부를 판정하지 않는다.
- 최신 상태 하나만 유지한다. 상태가 바뀌면 이전 발화(엔진 대기 포함)를 취소한다. 시작/복구는 400 ms, 확인 불가는 800 ms 안정화 후 안내한다. 이는 사용자 평가 전의 기본값이다.
- 터치 탐색을 쓰는 화면 읽기 기능이 켜져 있으면 앱의 자동 TTS는 생략하고 기존 TalkBack live region과 접근성 설명/액션을 유지한다. 터치 탐색이 없는 화면 읽기 기능까지 완전히 탐지하는 정책은 아니다.
- 자체 TTS 실패는 화면의 보조 설명과 진동으로 알린다. 정상인 공간음향을 TTS 실패만으로 종료하지 않는다. 일시적 발화 실패 후 다음 상태 안내는 다시 요청할 수 있다.
- 네트워크가 필요 없는 설치된 한국어 Voice만 허용하고 선택 반환값/실제 선택 결과를 검사한다. OS TTS 엔진은 제3자 서비스일 수 있으므로 이 조건만으로 엔진 자체의 네트워크 통신/개인정보 처리를 보증하지 않는다. 앱 권한/서버/네트워크 의존성은 추가하지 않는다.
- TTS 어댑터는 발화 원문을 logcat에 기록하지 않는다. 기존 Event.text는 화면 콜백 호환성을 위해 메모리로 전달한다.

## 상태 문구

| 조건 | 문구 |
| --- | --- |
| 준비 | 안내를 준비합니다. |
| 실제 안내 상태 안정화 | 안내를 시작합니다. |
| 사용자 일시정지 | 안내를 일시정지합니다. |
| 일시정지 후 실제 안내 재개 | 안내를 재개합니다. |
| 안내 도중 추적 상실 | 주변을 확인할 수 없습니다. 잠시 멈춰 주세요. |
| 바닥 확인 불가 | 바닥을 확인할 수 없습니다. 잠시 멈춰 주세요. |
| 추적/바닥 복구 | 주변 확인을 재개합니다. |
| 시작 실패 | 안내를 시작할 수 없습니다. |
| 출력 실패 등 세션 중단 | 오류로 안내를 멈췄습니다. |
| 사용자 안내 종료 | 안내를 종료합니다. |

"앱이 시작했습니다"는 최초 진입 때 유지한다. 홈/잠금/다른 화면으로 이탈하면 발화를 닫으며 종료 문장을 백그라운드에 남기지 않는다. 상태가 계속 같으면 반복하지 않는다. 안정화 시간을 넘겨 상태가 실제로 반복 전환되는 경우는 다시 읽을 수 있다. 장애물별 방향/거리 음성 및 상황 인지 말 목록은 이 변경에 연결하지 않는다.

## 안전 한계 설정

`TtsSafetyConfig`는 Android 어댑터 생성 시 주입하는 설정(기존 core JSON과 별도)이다. 초기화 10초, 시작 콜백 4초, 전체 발화 대기 12초, 완료 3초 + 글자당 250 ms(최대 30초). `StatusSpeechPolicy.Config`는 화면 상태 안정화 설정이다. 실제 음성 속도/엔진에 맞춘 기기 검증 후 조정한다.

초기화 실패는 현재 엔진을 닫고 화면 재진입에서 재시도한다. 발화 시작/완료 타임아웃은 해당 발화만 중단하고 감쇠를 해제하며 다음 요청을 허용한다. 관측 기반 발화의 시작 전 정보 나이 검사는 기존 `policy.maxInfoAgeMs`를 유지한다. Android 스케줄링과 제3자 엔진 응답을 실시간으로 보증하는 장치는 아니다.

## 검증

자동화 파일:
- `StatusSpeechPolicyTest`: 합성 상태/시계로 준비·실제 시작·재개·일시정지·종료·실패·중복 억제·짧은 추적 상실·복구·시계 역행 검사.
- `TtsSafetyConfigTest`: 제한 값의 기본값과 잘못된 설정 거부 검사.
- `.github/workflows/tts.yml`: 1118tts push 때 `:app:testDebugUnitTest :app:assembleDebug` 실행. 새 의존성은 추가하지 않았다.

작성 시 로컬 Kotlin 컴파일러가 없어 컴파일/단위 테스트는 실행하지 못했다. CI의 실제 결과와 아래 실기기 시험은 별도로 확인해야 한다. 단위 테스트는 Android TTS 엔진의 콜백/오디오 출력까지 검증하지 않는다.

실기기/엔진 장애 주입 체크리스트:
1. 최초 실행 직후 바로 시작/일시정지/재개/종료: 오래된 문장이 뒤늦게 재생되지 않는지.
2. 엔진 초기화 콜백 누락: 초기화 제한 후 화면/진동 알림, 감쇠 해제.
3. 발화 시작/완료 콜백 각각 누락: 제한 후 복구, 다음 발화 허용, 이전 늦은 콜백이 새 발화를 정리하지 않는지.
4. 오프라인 한국어 Voice 없음/다운로드 미완료/setVoice 실패: READY로 진행하거나 네트워크 Voice로 대체하지 않는지.
5. 비행기 모드에서 설치된 한국어 Voice: 상태 안내가 정상적으로 나오는지.
6. 발화 중 홈/잠금/설정 이동 및 복귀: 발화·타이머가 남지 않고 다시 초기화되는지.
7. TalkBack 켬/끔: 이중 자동 낭독, 버튼 이름/조작 접근성, 안내 상태 갱신 확인.
8. 공간음과 발화 동시 출력: 방향 구분 유지, 완료·취소·오류·타임아웃의 감쇠 복원 확인.
9. 실제 헤드폰/블루투스 경로와 전화 수신: 다른 앱 음성과 우선순위/청취 가능성 확인.
